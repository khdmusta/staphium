# دليل الإعداد — لوحة التحكم + Supabase + imgbb (خطوة بخطوة)

> الزمن التقريبي: 15 دقيقة. بعدها تتحكم بالمشاريع وآراء العملاء والمدونة
> (إضافة / تعديل / حذف / نشر) من `admin.html` بنفس تصميم الموقع.

## 1) إنشاء مشروع Supabase

1. ادخل https://supabase.com وأنشئ حساباً ثم **New project**.
2. اختر اسماً (مثل `rzgfolio`) وكلمة مرور للقاعدة واحفظها.
3. انتظر اكتمال الإنشاء (~دقيقتين).

## 2) إنشاء الجداول (SQL)

1. من القائمة الجانبية: **SQL Editor** → **New query**.
2. افتح ملف `supabase/schema.sql` من هذا المشروع، انسخ **كامل محتواه** والصقه في المحرر.
3. اضغط **Run** — يجب أن ترى Success.
4. تحقق: القائمة **Table Editor** يجب أن تظهر `projects` و `testimonials` و `posts` و `site_settings`.

> ملف `schema.sql` يشمل كل شيء (الجداول الأربعة + سياسات RLS).
> إن كنت قد نفذت نسخة قديمة منه سابقاً، نفّذ إضافياً ملف
> `supabase/migration-002-site-settings.sql` لإضافة جدول الإعدادات فقط.

> هذا الملف ينشئ أيضاً سياسات الأمان (RLS): الزوار يقرؤون **المنشور فقط**،
> وأنت (بعد الدخول) تدير كل شيء.

## 3) إنشاء مستخدم الداشبورد (كلمة المرور)

1. من القائمة: **Authentication** → **Users** → **Add user** → **Create new user**.
2. أدخل بريدك وكلمة مرور قوية، وفعّل **Auto Confirm User**.
3. اضغط Save — بهذا البريد وكلمة المرور تدخل إلى `admin.html`.

## 4) مفتاح imgbb (رفع الصور)

1. ادخل https://api.imgbb.com وسجّل الدخول.
2. من لوحتك انسخ **API key**.
3. (مجاني ويكفي تماماً لصور الموقع).

## 5) لصق المفاتيح في الموقع

افتح ملف `assets/js/cms-config.js` والصق قيمك الثلاث:

```js
window.RZG_CMS_CONFIG = {
  SUPABASE_URL: "https://xyzcompany.supabase.co",   // من: Project Settings → API → Project URL
  SUPABASE_ANON_KEY: "eyJhbGciOi...",               // من: نفس الصفحة → anon public
  IMGBB_API_KEY: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" // من imgbb
};
```

> احفظ الملف وحدّث الصفحة. قبل لصق المفاتيح يعمل الموقع بمحتوى Framer
> الأصلي ولا شيء ينكسر — وبعدها يقرأ المحتوى المنشور من Supabase تلقائياً.

## 6) الاستخدام اليومي

1. افتح `admin.html` في المتصفح (بنفس طريقة فتح الموقع — يفضّل عبر رابط الاستضافة).
2. سجّل الدخول بالبريد وكلمة المرور (خطوة 3).
3. اختر تبويباً: **المشاريع / آراء العملاء / المدونة / إعدادات الموقع**.
4. **المشاريع بأسلوب Behance**: زر «مشروع جديد» يفتح محرر نشر — صورة غلاف كبيرة
   أولاً، ثم اسم المشروع بخط كبير، مع **معاينة حية للبطاقة** كما ستظهر في الموقع،
   ثم السطر التعريفي والرابط والترتيب، وشريط نشر سفلي (نشر/مسودة).
5. **جديد** في الأقسام الأخرى: املأ الحقول → ارفع الصورة (تُرفع إلى imgbb تلقائياً)
   → **حفظ ونشر** (يظهر فوراً) أو **حفظ كمسودة** (يبقى مخفياً).
6. **إعدادات الموقع**: البريد، روابط X وLinkedIn، عنوان لوحة التواصل، سطر الحقوق —
   تُطبق على الفوتر مباشرة بعد الحفظ.
7. من البطاقة مباشرة: **تعديل / نشر / إلغاء النشر / حذف**.

## 7) ملاحظات مهمة

- **الرابط (slug)**: أحرف إنجليزية صغيرة وأرقام وشرطات فقط (مثال: `mihad-mobility`).
  للمشاريع يبني الرابط `./projects/xxx` وللمقالات `./blog/xxx`.
  > تنبيه: صفحات التفاصيل (`/projects/xxx`) نفسها صفحات Framer ثابتة —
>  الداشبورد تتحكم ببطاقات الأقسام في الرئيسية. إنشاء صفحات تفاصيل جديدة
>  للمشاريع/المقالات يتطلب خطوة إضافية (أخبرني عندما تحتاجها).
- **أول مقال منشور** يظهر كبطاقة مميزة كبيرة، والبقية كبطاقات عادية.
- **الترتيب**: الرقم الأصغر يظهر أولاً.
- حذف عنصر من الداشبورد يخفيه من الموقع فوراً.
- صور العملاء دائرية تلقائياً في الموقع — ارفع صورة مربعة لأفضل نتيجة.
- إن حذفت كل المنشورات من قسم، يعود الموقع تلقائياً لمحتوى Framer الأصلي
  (لا يظهر القسم فارغاً أبداً).

## 8) استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| الداشبورد تقول «أكمل الإعداد أولاً» | المفاتيح ما زالت `PASTE_*` في `cms-config.js` |
| «بيانات الدخول غير صحيحة» | تحقق من البريد/كلمة المرور في Authentication → Users |
| «تعذر الاتصال» | لا إنترنت، أو رابط Supabase خاطئ |
| «مفتاح imgbb غير مُعد» | الصق `IMGBB_API_KEY` في `cms-config.js` |
| الموقع لا يتغير بعد النشر | حدّث الصفحة (Ctrl+F5) — المحتوى يُقرأ عند التحميل |
| حفظ يفشل برسالة RLS/policy | تأكد أنك مسجل الدخول وأن SQL طُبّق كاملاً (أعد تشغيله) |
